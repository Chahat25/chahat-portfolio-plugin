# 💼 Chahat Portfolio WordPress Plugin + Personal Portfolio Dashboard

A full-stack portfolio experience combining a dynamic **WordPress plugin** and a custom-coded **personal portfolio dashboard** built with HTML, CSS, and JavaScript.

---

## 🧠 Features

### 🔌 WordPress Plugin

- ✅ Custom post type for adding/editing **Portfolio Projects**
- ✅ Admin panel to manage entries
- ✅ Easy-to-use shortcode: `[chahat_portfolio]`
- ✅ Responsive and accessible layout
- ✅ Built with clean, modular PHP

### 🌐 index.html Personal Portfolio

- 🎨 Fully responsive layout
- 🌙 Dark/Light Mode Toggle
- 🖋️ Typewriter Text Animation
- 💫 Scroll Reveal Animations (AOS.js)
- 🧠 Showcases Skills, Projects, Certifications, and Awards
- 🔄 Integrated AI + Web Dev theme and visuals
